# Release A 对象存储任务分类与额度边界

更新：2026-09-11。该文档定义 Release A 中所有可能发出对象存储数据面请求的路径。机器可读清单位于 [`infra/policy/media-storage-tasks.json`](../infra/policy/media-storage-tasks.json)，统一 Python 测试会检查任务分类、源码入口和直接 SDK 客户端没有漂移。

## 决策范围

目标是在 Cloudflare 免费账户和有限 S3/R2 额度下，优先停止非必要图片工作，同时保持文字站、账号、审核和权利下架可用。该策略不是供应商账单硬限额，也不承诺零费用；真实版本历史、存储类别、共享应用、账单水位和供应商延迟仍须在目标账户验收。

Release A 不自动采集，Release C 广告也未启用。这里不讨论未来采集器的图片下载或用户上传；这些功能加入前必须先扩展任务清单、准入和验收证据。

## 方案比较

| 方案 | 复杂度 | 风险 | 结论 |
| --- | --- | --- | --- |
| 给所有对象存储请求统一硬停 | 低 | 会阻断权利删除，也可能让已知公开 URL 长期存在 | 拒绝 |
| 只依赖告警和人工停机 | 低 | 告警延迟或无人处理时仍会继续产生请求 | 拒绝 |
| 按任务必要性分类，在发请求前分层准入 | 中 | 需要维护清单和多处合同 | 采用 |

采用第三种方式：非必要任务 fail-closed，必要删除保留独立预算和重试，用户图片读取由边缘策略降级到默认图。

## 当前任务清单

| 任务 | 触发方式 | 对象操作 | 分类 | 额度控制 |
| --- | --- | --- | --- | --- |
| 北京受控图片上传 | 人工 CLI 或管理员授权命令 | LIST/HEAD/PUT | 非必要 | 默认关闭；共享锁、上传状态、逐操作用量准入、两桶容量核算 |
| 定时全量图片对账 | 日本 Worker 定时发往北京 | LIST/HEAD | 非必要自动任务 | 默认关闭；调度前和跨区发出前两次读取持久用量状态 |
| 权利下架与到期删除 | 日本 durable outbox | HEAD/DELETE | 必要任务 | 不经过非必要额度闸门；严格签名回执、幂等和失败重试 |
| 公开图片读取 | 用户经 Cloudflare 网关请求 | GET | 请求路径 | 私有 R2 binding；策略异常或停图时不读 R2，返回本地默认图 |

Release A 没有第二个会自动遍历或写入对象存储的非必要后台作业。每日默认图检查只请求公开站内固定本地图；历史归档只写北京/日本受控文件；邮件、目录缓存刷新和用量 Analytics 查询也不读取对象本身。

## 新任务接入规则

任何新代码只要会发出 GET/HEAD/LIST/PUT/DELETE 或 multipart 数据面请求，就必须在合入前完成：

1. 在机器清单中登记区域、触发方式、操作类型、必要性、默认开关、失败行为和源码入口；
2. 非必要自动任务默认关闭，并在第一次供应商请求前读取当前用量状态；长任务还需在关键阶段重新检查；
3. 权利删除等必要任务不得复用“全部暂停”开关，必须有独立幂等、预算、告警和失败重试；
4. 新直接 SDK 客户端必须被静态合同发现；不能通过换文件或私有脚本绕开清单；
5. 更新环境模板、指标/告警、运行手册、回滚顺序和目标账户证据。

未来 Release B 自动采集如果处理图片，应作为新的任务类型单独评审，不能直接借用 Release A 人工上传凭据或绕过北京共享写入锁。

## 失败与恢复

- 用量状态缺失、过期、配置变化、超时或高风险时，上传和全量对账拒绝下一次非必要请求；不复用旧 permit。
- 上传发生不确定结果时保持 fenced/pending，人工对账后才能按精确 run ID 恢复。
- 权利删除失败保持 outbox retry/dead 证据，不把 HTTP 2xx 或额度拒绝写成已删除。
- 边缘策略不可用时 fail-closed 到默认图，并保持 `no-store`；恢复需要重新验证策略和缓存传播。
- 回退本清单和测试不会改变运行时开关；运行时回退须按各模块手册先停调度、保留状态和审计，再恢复旧版本。

## 验收边界

本地合同只证明当前源码入口已分类且已有控制没有被无意移除。它不证明真实 S3/R2 账单、Linux 锁、跨区网络、Cloudflare binding/cache/purge 或目标 PostgreSQL 已通过。公网发布仍以 [`RELEASE_A_READINESS.md`](./RELEASE_A_READINESS.md) 的真实环境门禁为准。
