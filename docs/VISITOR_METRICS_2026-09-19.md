# 全站 UV 与注册用户次数

用户明确确认“两种都需要”。实现范围：保留全站详情 PV/热点和逐注册用户访问次数，增加匿名与登录浏览器统一的第一方 UV。UV 不是自然人数，同一人换浏览器/清空存储会形成新的访客，不能与账号数混称。

## 口径与选择

- 访客明确允许后才在浏览器本地生成随机 UUID；不使用 IP、User-Agent、设备指纹，不向第三方分析服务发送数据。随机标识最多使用 30 天，过期轮换。
- 拒绝、未选择、浏览器 GPC/DNT 或存储不可用：仍计原有匿名详情 PV，但不计 UV。后台必须显示“同意统计的浏览器 UV”和已覆盖的详情 PV，不能冒充所有访问者人数。
- 同一随机标识跨匿名/登录状态保持一致；服务端仅保留其 SHA-256、上海日期及每日访问次数，不写入所看实体或账号 ID。注册用户访问次数仍按现有历史记录另算。
- 范围 7/30 天内按哈希去重；累计 PV 可长期展示，但累计视图的 UV 限最近 30 个自然日，不回填上线前 UV。每日 UV 不直接相加当期间 UV。
- UV 行仅保留最近 30 个自然日，服务启动及每小时清理过期行，最多一小时清理延迟。关闭选择后立即停止未来 UV、清除本地标识，既有去标识记录随期限清理；不改变个人浏览历史保留规则。
- 仅进入当前已发布详情且上报成功才计数；PV 与 UV 在同一事务写入，无效/隐藏/已删除详情均不得增量。
