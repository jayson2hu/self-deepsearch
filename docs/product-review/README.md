## 独立访问服务

[服务脚本](../../scripts/serve_product_review.py)只提供该 HTML 与下载入口，不提供仓库目录、源文件或环境文件。除不含业务信息的健康检查外，所有请求均需访问密码。

```bash
python3 -B scripts/serve_product_review.py \
  --host 127.0.0.1 --port 13002 \
  --auth-file /absolute/private/path/access.json
```

凭据文件放在仓库外的私有目录，权限设为 `0600`，包含 `username` 和独立随机生成的 `password`；密码至少 20 个字符。不将实际访问凭据写入文档或 Git。

当前可在自己的电脑上通过 SSH 转发访问（替换登录用户与服务器地址）：

```bash
ssh -N -L 13002:127.0.0.1:13002 登录用户@服务器地址
```

保持该 SSH 会话开启，在本机浏览器打开 `http://127.0.0.1:13002/#seo`，输入单独提供的访问凭据；本机到服务器之间由 SSH 加密。服务器的 `127.0.0.1` 不是用户电脑可直接访问的公网地址，未建立转发时该浏览器地址不会连到服务器。

若以后需要直接公网访问，应在明确授权后部署 HTTPS 入口并保留认证，不开放明文认证端口。HTML 与审查记录导出不依赖服务长期运行。
