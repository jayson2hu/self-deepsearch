## 实际交付

- 新增统一 `returnTo` 校验，只接受已知站内路由及白名单查询参数；拒绝外域、协议相对地址、反斜杠、控制字符、结构性百分号编码、多重编码、嵌套 `returnTo`、片段及未知路由。
- 登录、注册、密码重置之间保留已经校验的目标；普通登录仍回首页。密码重置不建立会话，完成后明确返回登录。
- 游客明确点击收藏或关注时，才在当前标签页 `sessionStorage` 写入 15 分钟意图；存储不可用时仍可安全返回原页面。URL 和存储均不含邮箱、口令、验证码或反馈正文。
- 登录/注册成功先返回原作品或人物资料，展示“继续收藏/关注”确认；只有再次点击确认才发送现有 POST。取消、完成、过期、已存在关系和目标不可用均有清理或提示。
- 新增统一 404 处理：若返回目标已下架或不存在，清理匹配意图，明确说明没有执行关系操作并提供搜索入口。
- 收藏/关注确认使用设置型 POST；数据库 `ON CONFLICT` 行为增加真实 PostgreSQL 幂等合同测试。
