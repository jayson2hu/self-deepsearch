# Self Deepsearch · 20 个设计方向

设计评审版本：2026-10-15。用途：挑选视觉方向，不替换现有业务应用。

## 边界与使用者

英文优先的 18+ 作品资料索引；只展示合成资料，不含视频、下载、露骨图片、真人照片、真实账号或真实统计。目标国家及最终内容边界等待站点所有者确认。公开站服务查找、浏览、收藏；运营端服务采集审阅、资料编辑、权利投诉和发布。每个方向覆盖当前 25 个公开页面、26 个运营页面，并额外提出年龄核验、内容投诉、Cookie 偏好页面。

## 设计流程与复核

使用临时安装的 `frontend-design` skill 先形成此计划，再实现、截图、修正。通用 SaaS 大数字首屏和重复圆角卡片不能表现“资料档案馆”，所以首页改为作品索引、编辑精选或检索入口；后台保持真实工作队列语义，不做无意义装饰图表。20 个方向中允许保留报刊、深色、复古等明确风格，但必须用导航、信息排序、版面比例和阅读密度区分，不能只替换颜色。

基础字体只用系统字体栈，无外部字体追踪或字体下载。下表字体分别表示标题 / 正文；设备缺失时使用相应 serif / sans-serif / monospace。文本左对齐为默认；仅搜索聚焦、封面及对称方向使用居中标题。正文以 16px 为基准；后台 14px；交互目标采用 44px 设计目标。尊重 reduced-motion，不使用自动轮播。

## 布局骨架

```text
封面型  [标志 / 导航]       编辑型 [标志 / 检索]       索引型 [侧栏 | 检索]
        [标题 | 主封面]            [巨字刊头]               [     | 筛选]
        [分类 / 条目横列]           [精选大图 | 近期小项]       [     | 条目列表]

运营侧栏型 [导航 | 状态与操作]  运营横栏型 [标志 / 导航 / 账号]
           [     | 队列 | 详情]            [待办 | 变更]
           [     | 审计记录]              [工作表 / 编辑表单]

移动端 [标志 / 菜单] → [标题与主操作] → [可折叠筛选] → [卡片/逐项表格]
```

移动端不使用缩小桌面站代替响应式页面；审核台中“桌面”缩放仅用于在一个窗口并排观察两个真实桌面视口。后台表格在小屏变为带字段名的条目，主要操作不隐藏。

## 交互与边界

- 审核：20 套总览、公开/运营切换、完整页面切换、双方案比较、桌面/手机、收藏、逐页意见、导出/导入 JSON。
- 预览：导航、搜索、筛选、收藏演示、表单校验、删除确认；所有操作明确为合成演示，不连接业务 API，不提供真实注册或发布。
- 状态：正常、空、加载、服务异常、拒绝访问；年龄核验另有待处理、服务不可用、地区限制，不提供验证绕过。
- 合规：入口提示、隐私选择、无需登录的权利/非自愿内容投诉；以“待实现并审核”标记，不把设计稿当作运营承诺。
- 安全：预览服务器只允许静态审核文件；默认回环地址；不索引；不加载第三方字体、追踪或内容。

## 视觉素材

`imagegen` 已按非露骨抽象封面请求调用，但工具未返回可用图片文件，因此本版不声称包含生成位图。所有封面采用项目内原创 CSS 几何与排版，标为“Design placeholder”；人物仅用文字首字母，占位不代表真实演员。没有把现有真实业务图像复制到审阅包。
