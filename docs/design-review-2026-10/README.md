# 20 套设计审核台

这是可交互的**设计候选集**，不是 20 套已接入真实业务的生产主题。现有公开站、运营后台、API、数据库和 Docker 部署均未替换。页面使用英文，审核工具使用中文；数据全部合成，不含露骨内容、真人肖像或真实凭据。

## 打开审核

在项目根目录运行：

```bash
npm run preview:design
```

然后打开 [本机审核入口](http://127.0.0.1:13004/)。没有 Node 的审核电脑也可以在项目/审核包根目录运行：

```bash
python3 scripts/serve_design_review.py --port 13004
```

服务器只监听 `127.0.0.1`，因此在自己电脑直接输入远程服务器的 `127.0.0.1` **不能访问**。可在自己的电脑建立 SSH 隧道：

```bash
ssh -N -L 13004:127.0.0.1:13004 用户名@服务器地址
```

保持 SSH 连接，再在自己电脑打开 `http://127.0.0.1:13004/`。无需新增对公网开放的安全组端口。审核服务器不提供 `--host 0.0.0.0` 参数；需要公网审核时，应另行确认带认证的测试发布方式，不复用生产站。

不要双击 `index.html` 用 `file://` 打开：ES modules 需要 HTTP 服务。

Ubuntu 服务器可使用独立 Docker 服务常驻运行：

```bash
docker compose -f docs/design-review-2026-10/compose.yaml up -d
```

此服务名为 `self-deepsearch-design-review`，与业务测试栈分开；使用只读挂载、非 root 用户和本机 13004。Linux host 网络用于保留服务器的回环绑定，不创建公网监听；不与同时运行的 `preview:design` 共用端口。停止时运行同一 Compose 文件的 `down`，不影响业务容器。便携包在审核电脑上仍可直接使用 Python。

也可在完整项目运行 `python3 scripts/package_design_review.py`，生成 `.cache/design-review/self-deepsearch-design-review.zip`。便携审核包只含明确列出的静态文件、60 张截图和预览服务器，不含业务数据、凭据、Git 或 npm 项目；解压后按 `START_HERE.md` 使用 Python 3.9+ 命令即可。下方 npm 验收命令只适用于完整仓库。

## 怎么审核

1. 在「20 套总览」按深色、编辑、高效、复古、柔和、实验、极简筛选，切换公开站桌面、运营后台桌面或手机截图，收藏感兴趣的方向。
2. 点击「进入审核」，切换公开站 / 运营后台及具体页面。
3. 选择桌面 1440px 或手机 390px；桌面画布的缩放仅是审核工具，手机页面是实际响应式布局。
4. 开启「并排比较第二套」。两个预览同步页面与状态；意见记录在**主方案**，不是对比方案。需要评价对比方案时把它切换为主方案。
5. 切换正常 / 空数据 / 加载 / 服务异常 / 无权访问状态；年龄核验提案另有待处理、供应商故障和地区限制演示。
6. 填写「进入候选 / 需要修改 / 不采用」及意见。记录按方案、端、页面、设备、状态隔离。
7. 导出 JSON 备份或交给开发。收藏和意见默认仅在当前浏览器 localStorage；更换浏览器或清理网站数据会丢失本地记录。存储不可用时会提示导出。

导入是**合并**：收藏取并集；同一键的意见以导入文件为准，其他意见保留。限制 2 MB 文件、单条 4,000 字符，拒绝未知方案/页面/状态/版本和重复键；导入文本不会作为 HTML 执行。

建议先从以下组合缩小范围（这是设计判断，不是推荐替你定稿）：

- 公开站：01 午夜首映、02 编辑手记、13 参考图书馆。
- 运营端：10 石板控制台、17 数据图鉴、18 无障碍极简。
- 如需更强视觉表达，再对比 08 信号实验、14 钴蓝工作室、16 幕外画册。

允许选择不同的公开站和运营端方向。定稿后再拆分实施到真实 Next 应用，接入 API、鉴权、权限、服务状态和回归测试。

## 覆盖范围

- 当前公开站 **25** 个页面模板，包含动态详情和账户页。
- 当前运营端 **26** 个页面模板，包含采集详情、编审、媒体、权利、安全、SEO 和流量。
- 额外 **3** 个新增页面提案：年龄与访问、公开投诉、Cookie 偏好；不是已有生产路由。
- 全部 **54 × 20** 个页面/风格组合都有桌面与手机布局。动态路由按模板覆盖，不代表所有真实数据库记录已经验收。
- 20 种独立布局标识，采用分屏封面、刊物、严格网格、档案侧栏、书架、对称剧院、留白、拼贴、频道、搜索控制台、画廊、报刊、图书馆、巨字窄图、横幅叙事、非对称画册、数据列表、强对比单轴、胶片、检索书架等结构。

具体配色、字体、布局与取舍见 [设计说明](DESIGN_SPEC.md)。页面清单唯一数据源是 [data.mjs](data.mjs)，验收会与实际 `app/**/page.tsx` 比较，漏页或新增路由未覆盖会失败。

## 哪些交互是真实的

审核台收藏、意见、导入导出、导航同步是可用功能。预览中的搜索/筛选、表单浏览器校验、收藏切换、确认对话框、表格过滤、核验失败状态和隐私选项可操作。

业务注册、登录、发送邮件、发布、上传、合并、删除、数据导出、投诉受理和年龄核验**没有连接真实服务**。这些操作有明确的演示提示，不会修改业务数据。有些业务按钮只展示交互反馈，不代表完整业务功能已实现。

## 浏览器验收

复用项目现有 `@playwright/test` 与 Chromium，不增加 npm 依赖。测试自动启动随机端口回环预览并在结束后停止；不会占用审核入口或调用业务 API。

```bash
npm run test:design
npm run test:design:browser -- --mode smoke
npm run test:design:browser -- --mode matrix --workers 4
npm run test:design:browser -- --mode narrow --workers 4
npm run capture:design
```

`--mode all` 依次运行截图、交互、全矩阵和 320px 关键页面检查。可用 `--themes 01,10` 缩小修复回归范围。

若找不到 Chromium，设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指向已安装的浏览器；测试也识别当前项目已有的本地缓存路径。测试结果及失败截图写入被忽略的 `.cache/design-review/`，60 张正式缩略图写入 `thumbs/`。运行 `capture:design` 会有意更新这些生成截图。

检查包括路由完整性、20 套基础文字配色（五组至少 4.5:1；强调色/画布至少 3:1）、唯一主标题、页面脚本错误、外部请求、水平溢出、320px 关键页面、导航、筛选、确认与焦点、审核持久化和不可信导入。**这些检查不是完整 WCAG 2.2 认证，不涵盖所有读屏器、平台浏览器或所有实际内容。**

## 面向海外成人用户

见 [上线准备清单](LAUNCH_CHECKLIST.md)。以下信息仍需提供：

- 目标国家/州/地区；是否允许全球访问。
- 是否继续仅提供元数据与有权展示的图片，还是计划加入露骨图片、视频或其他功能。
- 运营主体、隐私/权利联系方式、内容授权来源、年龄核验与投诉处理负责人。

未确认之前不能承诺“符合所有海外成人网站标准”。本稿不集成年龄核验供应商、不接收身份证件、不把点击 18+ 当成真实核验、不假造成年/同意/版权证明。

## Skills 与素材来源

- 使用系统 `skill-installer` 从公开 [Anthropic skills](https://github.com/anthropics/skills) 临时获取 `frontend-design` 和 `webapp-testing`；位置在 `/tmp`，没有改变全局 skill 配置，也不要求其他审核者安装 skill。
- `frontend-design`：先确定 20 套 tokens/结构/取舍，再实现与截图批评；不把换色当作完整设计方案。
- `webapp-testing`：读取完整说明，运行其 `with_server.py --help` 并用于本机服务生命周期验证；按“先等页面稳定、观察 DOM/截图、再操作”检查。Python Playwright 临时下载未成功，浏览器验收改用仓库已有 Node Playwright；未留下额外 Python 依赖或未验证的 Python 浏览器脚本。
- `imagegen`：读取说明及提示参考，调用内置图片工具请求非人物抽象画廊封面；工具未返回可用文件，本版没有生成位图。最终封面为原创 CSS 几何，不是对真人或作品的仿制。
- 图片请求记录：`Landscape 1536x1024; original non-figurative editorial gallery artwork; pale stone arch, matte terracotta disc, dark teal architectural panels; warm directional light, tactile plaster and stone; no people, bodies, sexual content, text, logos or watermark; explicitly a design placeholder, not a real performer or film.`
- 字体均为系统字体栈；图标为项目内少量 SVG 路径。没有下载第三方字体、照片或商业模板。`thumbs/*.jpg` 是该原型的浏览器截图，不是产品摄影或真实内容素材。

本次使用技能带来的实际变化：设计有明确的布局差异与移动取舍，验收采用实际浏览器而非仅静态检查，并将待核实的上线条件与可操作的设计提案分开。
