## 截图复核和修正

人工查看了 20 套总览、代表性深浅主题、报刊、强对比、数据索引、运营桌面与手机页面。发现并修复：

- 审核页缺少主标题：改用明确的一级标题。
- 筛选框的名称不明确：补充与可见标签一致的无障碍名称。
- 对比截图可能在第二个窗口加载前截取：改为确认两个窗口的实际方案和页面已渲染。
- 手机意见表单影响预览阅读顺序：将意见移至预览之后；桌面预览随阅读保持可见。

没有把一次自动化通过等同于人工审核定稿；最终风格、密度、英文文案及真实内容效果由站点所有者审阅。

## 重现

在完整仓库中：

```bash
npm run test:design
npm run test:design:browser -- --mode smoke
npm run test:design:browser -- --mode matrix --workers 4
npm run test:design:browser -- --mode narrow --workers 4
npm run capture:design
```

当前环境：Ubuntu、Node 22.22.2、项目已有 Playwright 和 Chromium 缓存。浏览器执行路径可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。原始结果位于完整仓库的 `.cache/design-review/*-result.json`；此目录为本地生成证据，便携包只带本记录及设计截图。

## 证据边界与待审核事项

- 全矩阵是页面模板与响应式检查，不逐条验证数据库中的真实记录。
- 原型的业务按钮、投诉、登录和年龄核验未接入真实服务；审核台自身的本地意见功能可以使用。
- 对比度测试覆盖基础 tokens，不是对所有图片、覆盖层、读屏器和浏览器组合的完整 WCAG 审计。
- 目标国家、内容类型、运营主体、真实素材权利及合规适用待确认，见 [上线准备清单](LAUNCH_CHECKLIST.md)。
- 现有公开站、运营站、API、数据库和 Docker 运行环境未因本轮改版；选定方向后的生产实施另行验收。
