待站点所有者确认
年龄与隐私

证明符合年龄条件，不收集多余身份

在适用情形接入有效年龄核验；验证失败或服务不可用时不放行受限内容。仅点“18+”不能代表实现了法定核验。

内容权利

来源、成年与同意有据可查

按内容与角色要求核实权利、授权及成年/同意证据。公开抓取并不等于拥有再发布许可；不能用合成材料替代证据。

需业务流程与法务核实
投诉与安全

无需登录，也能报告问题

为非自愿内容、疑似未成年、版权和错误资料提供入口、分级受理、移除/限制及申诉流程，按适用规则配置时限。

隐私选择

明确告知，默认少收集

完善真实隐私告知、保留期限、处理方清单和数据权利渠道。可选追踪默认关闭，拒绝与同意同样易用。

无障碍与安全

可读、可操作、可退出

检查键盘、对比度、焦点、320px 重排、错误状态；上线前另验 HTTPS、权限隔离、私有页禁止缓存与索引、日志脱敏和供应商政策。

设计检查 ≠ 完整 WCAG 或安全认证

核查依据与限制

设计参考 W3C WCAG 2.2 和 欧盟委员会年龄核验说明（2026-10-15 可读取）。Ofcom 与 FTC 页面本次返回 403，未据此宣称核实其具体门槛或时限。美国州法、英国、日本及其他国家规则需在市场范围确定后另行核实。
