## FU-01 设计

使用 OpenCC 官方固定版本 1.1.9 的 TSCharacters 与 JPVariants 单字字典构造搜索等价字形表，保留 Apache-2.0 许可、来源和 SHA-256。仅作为宽松召回，不进行词组翻译或身份推断；库内原文完全匹配仍优先。归一不回写任何人物姓名，不自动合并相同折叠结果。运行期本地嵌入，不依赖网络服务；Python 预览与 Go API 使用同一份生成表。

原有未完成与历史验收记录保留，本文件记录增量结果，不覆盖过去的失败或代签产品验收。

FU-01 已生成 4,336 项字形映射；仅人物搜索与采集预览新增字形召回，作品/厂牌搜索未改变。初版全字典 SQL 转换在 4,196 条预览资料上耗时约 3.5–4.5 秒，已改成“只传查询涉及的字形等价组”，相同数据实测约 122–423ms（含 psql 启动及连接开销，不作为生产 SLA）。真实等价查询：三上悠亜/亞/亚各 1；橋本/桥本各 12；AIKA/aika/全角各 5，人物 ID 集合一致。未经收录的“深田咏美”仍为 0，不把字形归一冒充译名推断。[只读数据库证据](evidence/followup-2026-09-19/search-variants-database.json)。
