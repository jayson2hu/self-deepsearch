## 本版范围

查询优先；保留关联浏览；无广告时无占位、有合规有效广告时访客和登录用户都可见；详情新增公开资料更新时间；不向访客展示来源核验/审核工作流；登录后回到原任务；“不感兴趣”只影响推荐；搜索分两步扩展实体类型。SEO 已按用户后续授权采用[正式推荐基线](../PRODUCT_SEO_PLAN.md)：中文产品、Google 官方规范首批技术验收、明确索引和图片预览规则；不是已部署或已收录。

D-03 仅确认“说明先行、评估主动开启及有限保留”，未确认具体保留天数或旧记录删除。D-06 先落实前台不展示，后台已有权限、审核和下架机制不作推断性删除。D-07 的标题按资料标题/名称设计，不额外增加来源标题列表；详见 Q-06。

## 文档优先级

审核原文 → 本包决策记录 → 本包产品/技术/任务/验收 → 旧评审候选稿。若未来审核有变，先更新决策再改下游文档。

[原产品规划](../../PRODUCT_PLAN.md)同步已确认的方向，但实际运行能力仍以代码和证据为准。[原架构](../../ARCHITECTURE.md)、[详细架构](../../PLATFORM_ARCHITECTURE.md)的部署、安全、媒体边界继续生效。本文档包仅是增量设计，不取代[Release A 发布门槛](../RELEASE_A_READINESS.md)。

[历史 HTML 审查页](../product-review/index.html)用于保留原评审上下文和浏览器中的审查草稿，不是新的开发计划或进度看板；不会自动读取本次粘贴的审核意见。请以本目录为后续开发入口。
