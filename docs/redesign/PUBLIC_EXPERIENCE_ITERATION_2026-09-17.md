# 公开站广告、浏览统计与主题迭代执行书

版本：UX2 v1 / 2026-09-17（Asia/Shanghai）  
状态：方案已冻结，进入开发  
范围：公开站列表广告、详情浏览口径、公开浏览数量、浅色/深色主题；不改变后台主题、账号历史生命周期、搜索页广告和真实广告供应商。

## 1. 产品结论

### UX2-01 列表广告

现状并非完全没有列表广告：最新发行、最近收录和热门浏览只有在单页至少 12 条时，才在第 8 条之后请求信息流广告；当前审查数据只有 8 条，因此用户看不到。人物、厂牌总列表没有广告位。

本轮调整为：

- 最新发行、最近收录、热门浏览、人物资料和厂牌资料列表，在本页自然内容达到 8 条时，于第 8 条之后请求一个信息流广告。
- 最新发行、最近收录、热门浏览继续保留桌面右侧栏；人物和厂牌列表新增桌面右侧栏。
- 每个列表页最多一个信息流广告；桌面最多再有一个侧栏广告。手机不展示侧栏。
- 广告必须标记“广告”和广告主；无已发布素材、排期失效、接口异常或尺寸不符时完全隐藏，不保留空白。
- 搜索、登录注册、账号、隐私/条款、错误与空结果页不新增广告。搜索是明确任务，不用广告打断。
- 翻到下一页后按该页自身内容重新判断，不因为页码增加而强制展示。

### UX2-02 浏览计数口径

“浏览”定义为浏览器真实进入已发布作品、人物或厂牌详情页后，由详情页客户端上报成功。以下行为不计浏览：

- 打开首页、列表、搜索结果或账号页面；
- 点击“下一页”或切换热门时间范围；
- Next.js 链接预取、搜索引擎抓取普通详情 GET、服务端生成 metadata；
- 请求不存在、草稿、隐藏或下架对象。

当前代码已经把详情读取与浏览上报分离：详情 GET 不写统计，只有详情页挂载的 `PageViewReporter` 调用 `POST /api/v1/metrics/page-view`。React Strict Mode 的同一挂载重复执行已去重。本轮不改成列表曝光统计；新增回归用例锁定“列表翻页为 0、详情上报为 1”。刷新或离开后重新进入属于新的浏览，不宣称是独立访客。

### UX2-03 公开统计数量

公开详情增加两项聚合数字：

- 近 30 天浏览；
- 累计浏览。

数字来自现有 `content_metrics_hourly` 小时聚合，仅表示详情浏览次数，不表示独立用户数、真实人数或播放量。作品、人物和厂牌使用同一口径；没有数据时显示 0。列表卡片暂不全部展示数字，避免把最新/人物/厂牌目录变成排行榜；热门页后续可单独增加与所选时间范围一致的数字。

公开响应只返回聚合数，不返回账号、IP、浏览历史或小时明细。详情初次 HTML 是请求时快照，本次进入产生的计数可在后续刷新中体现。

### UX2-04 浅色/深色主题

公开站页头加入主题切换按钮：

- 首次访问跟随操作系统；点击后在浅色和深色之间切换，并保存在同站点主题 Cookie 中，服务端首屏可直接使用。
- 在 React 水合前应用主题，避免先亮后暗闪烁；禁用本地存储时仍可使用当前页面主题。
- 所有正文、卡片、表单、提示、广告边框、焦点状态和默认图片背景满足可读性；真实图片不做反色或滤镜。
- 主题只改变表现，不改变 HTML 主体、canonical、结构化数据、广告选择、统计上报或索引策略。
- 运营后台本轮保持现状，避免把公开站视觉偏好扩大为后台重构。

## 3. 验收标准

| ID | 验收项 | 通过条件 |
| --- | --- | --- |
| UXA-01 | 0、7、8、24 条列表 | 少于 8 条无信息流广告；8 条及以上恰有一个第 8 条后广告；自然内容顺序和序号连续 |
| UXA-02 | 五类列表与搜索/账号页 | 五类允许页可展示；搜索、账号和空态无广告 DOM；无填充不留空白 |
| UXA-03 | 桌面/手机广告 | 1200px 及以上可有侧栏；1199px 及以下无侧栏；信息流不横向溢出 |
| UXA-04 | 浏览计数 | 列表打开、翻页、预取均不增加；实际进入三类详情后各增加 1；未发布对象拒绝上报 |
| UXA-05 | 统计显示 | 三类详情返回并显示 30 天与累计值；数字与数据库聚合一致；无个人数据 |
| UXA-06 | 主题首屏 | 系统深色首次访问无亮色闪烁；手动选择刷新后保留；存储失败可继续使用 |
| UXA-07 | 主题可用性 | 390/768/1200/1440px 下正文、表单、卡片、广告和焦点可辨，无横向溢出 |
| UXA-08 | 回归与交付 | OpenAPI、TypeScript、lint、Go、构建、真实浏览器和目标审查栈通过；每个实现包单独提交 |

## 5. 回退

- 列表广告可暂停对应活动；无活动时页面自动回到无广告布局，不需要重新部署。
- 统计字段为向后兼容新增；旧前端会忽略，回退前端不影响现有聚合写入。
- 主题异常时可移除切换组件并让变量回到浅色默认；本地偏好不包含账号或业务数据。
- 本轮不执行数据库迁移，不修改历史数据，不引入第三方广告脚本。
