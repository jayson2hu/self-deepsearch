# 原生作品卡广告与推荐位回退执行书

版本：UX3 v1 / 2026-09-17（Asia/Shanghai）

状态：方案冻结，进入开发

关联基线：[公开站广告、浏览统计与主题迭代执行书](./PUBLIC_EXPERIENCE_ITERATION_2026-09-17.md)

## 1. 修订原因

上一版把列表广告实现为第 8 个作品之后的横向信息流。产品复核后的真实意图是：广告可以作为一张与作品卡同宽的原生卡片进入作品网格，占用一个视觉卡位；推荐区域也使用相同机制。没有可投放广告时必须继续显示正常作品，不得出现空白卡位，也不得为了广告永久丢失作品。

## 2. 产品规则

### UX3-01 作品列表

- 最新发行、最近收录的第 8 个网格位置为原生广告候选位；热门浏览属于推荐场景，第 4 个位置为候选位。
- 有有效广告时先显示广告卡，原第 8 个及后续作品顺延；接口返回的作品不能因广告被删除或跳过。
- 无广告、排期失效、素材不合规或广告接口异常时，不输出广告 DOM，作品自然补位。
- 列表作品展示结束后增加一个横幅广告位；无广告时完全隐藏，不保留高度。
- 桌面侧栏广告维持现有规则，手机不展示侧栏。

### UX3-02 推荐区域

- 首页“最新发行”推荐区、作品详情“相关作品”、人物详情“关联作品”和厂牌详情“关联作品”的第 4 个网格位置为原生广告候选位。
- 原生广告必须明确显示“广告”和广告主，不使用作品编号、排名或“不再推荐”操作，避免被误认为作品。
- 没有广告时作品补位；有广告时作品顺延，所有返回作品仍可见。
- 广告展示与用户的“不感兴趣”记录相互独立，不把广告写入收藏、推荐偏好或浏览历史。

### UX3-03 原生广告形态

- 新增 `native` 广告形态，固定素材比例为 `640 × 400`，与作品封面 `16:10` 一致。
- 广告卡正文区域显示标题、广告主和“广告”标记；允许无跳转模拟广告。
- 原生广告仅占网格单元，不横跨整行；390px 手机按两列作品网格自适应。

## 3. 稳定广告位

| 页面 | 原生卡位 | 列表/区块下方 | 桌面侧栏 |
| --- | --- | --- | --- |
| 首页推荐 | `home.recommendation_card` | `home.after_latest` | `home.desktop_right` |
| 最新发行 | `latest.native_card` | `latest.after_grid` | `latest.desktop_right` |
| 最近收录 | `recent.native_card` | `recent.after_grid` | `recent.desktop_right` |
| 热门浏览 | `popular.native_card` | `popular.after_grid` | `popular.desktop_right` |
| 作品相关推荐 | `work.related_card` | 不新增 | `work.desktop_right` |
| 人物关联作品 | `performer.related_card` | 不新增 | `performer.desktop_right` |
| 厂牌关联作品 | `studio.related_card` | 不新增 | `studio.desktop_right` |

旧的 `latest.after8`、`recent.after8` 和 `popular.after8` 在新前端不再请求；审查环境验证后暂停对应模拟活动。人物与厂牌总目录不是作品网格，本轮不把原生作品广告卡混入实体目录。

## 4. 技术方案

- OpenAPI、共享类型、API 参数校验和运营广告表单增加 `native` 形态及 `640 × 400` 固定尺寸。
- 广告组件允许作为 React 节点注入作品网格；网格在指定索引前插入节点。
- 后端初次解析无广告时返回空节点；后续轮询失去广告时节点消失，作品通过 CSS Grid 自动补位。
- 插入广告不修改作品数组、作品排名参数、游标或详情浏览上报。
- 下方横幅继续使用 `banner` 形态，避免把横幅素材强行裁切成作品卡。

## 5. 验收标准

| ID | 验收项 | 通过条件 |
| --- | --- | --- |
| UX3-A01 | 列表原生卡 | 最新发行、最近收录有广告时第 8 位为广告；热门浏览第 4 位为广告；广告是单个网格单元，不横跨整行 |
| UX3-A02 | 推荐原生卡 | 四类推荐/关联作品区有广告时第 4 个网格位置为广告 |
| UX3-A03 | 无广告回退 | 未配置、暂停、过期、错误响应时无广告 DOM、无空白单元，原位置显示作品 |
| UX3-A04 | 作品完整性 | 开关广告前后作品 ID 集合相同；广告只使作品顺延，不删除作品，不改变下一页游标 |
| UX3-A05 | 下方横幅 | 三类列表作品网格之后可显示一个横幅；无广告时不保留高度 |
| UX3-A06 | 响应式 | 1440px 原生广告占四列中的一列；390px 占两列中的一列；无横向溢出 |
| UX3-A07 | 广告辨识 | 卡片可见“广告”、广告主，且没有作品编号、排名和推荐偏好按钮 |
| UX3-A08 | 回归 | 类型生成、TypeScript、lint、构建、Go、合同测试、真实浏览器和审查环境通过 |

## 7. 回退

- 暂停原生广告活动后，作品立即自动补位，不需要重新发布目录数据。
- 回退前端后，新 `native` 活动不会被旧页面请求，不影响现有横幅和侧栏广告。
- 本轮不执行目录数据迁移，不修改浏览计数口径，不引入第三方脚本。
