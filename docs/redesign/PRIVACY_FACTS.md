# DEV-07 当前数据行为核对清单

核对日期：2026-09-16（Asia/Shanghai）。本文件供开发、验收和后续政策更新使用；面向用户的简化说明位于 `/privacy` 与 `/about`，不公开内部字段名、操作人或安全实现细节。

| 面向用户的事实 | 当前实现证据 | 页面表达边界 |
| --- | --- | --- |
| 匿名详情浏览不写账号历史 | `account_handlers.go` 只有存在有效用户会话时调用 `RecordHistory`；聚合浏览仍调用 `RecordPageView` | 只说按资料/小时累计、匿名不写账号历史；不宣称所有基础设施日志都不存在 |
| 登录用户详情浏览默认写历史 | `RecordHistory` 向 `platform.view_history` 追加作品/人物/厂牌及时间 | 明确当前没有停止未来记录的用户开关 |
| 清除可见历史是软清除 | `ClearHistory` 只设置 `is_deleted/deleted_at`；列表只读未清除行 | 使用“不再展示、不会物理删除”，不得写“永久删除” |
| 已清除历史可归档，但默认关闭 | Worker `HISTORY_ARCHIVE_ENABLED=false`；启用后只处理达到最小年龄的已清除行 | 不把 30 天配置默认值写成统一保留期限或已启用承诺 |
| 归档不删除数据库原行 | 历史归档写 gzip JSONL、manifest 和 `archived_at`；Release A 无物理清理 | 明确归档与删除不同，恢复不得重新显示已清除记录 |
| 关闭账号关闭登录而非全量删除 | `CloseAccount` 设置 `account_status=closed`、撤销会话并写关闭事件，没有删除账号关系/历史/反馈 | 明确无法登录和不再展示；不得声称账号资料已全部删除 |
| 账号关系和反馈为私有能力 | 收藏、关注、推荐偏好、历史和反馈 API 需要认证，私有 fetch 使用 no-store | 不列出内部审核理由；只说明保存关系、提交内容和处理状态 |
| 注册登录处理安全与防滥用数据 | 邮箱挑战、密码派生、会话、限流/安全摘要由身份服务处理 | 不公开摘要算法参数、密钥、内部风控维度；可以说明密码不明文保存 |
| 联系邮箱必须由环境提供 | `RIGHTS_CONTACT_EMAIL` 通过格式校验且拒绝 `.invalid` 示例；日本 Compose 要求显式配置 | 无有效值时显示环境未配置警告，不输出示例邮箱冒充正式联系方式 |

## 尚未实现、不得承诺

- 没有 `history_sync_enabled` 用户开关，Q-01 未确定默认值和老账号迁移。
- 没有覆盖在线记录、归档和备份的统一有限保留期限。
- 没有“永久删除全部数据”的用户操作或已验收物理清理任务。
- 关闭账号不是删除反馈、审计、安全记录或历史原行。
- 联系邮箱只有在目标环境配置并由负责人核实后，才满足正式开放门禁。

任何数据生命周期变更都要同时更新本清单、用户说明、账号关闭 notice version、OpenAPI/迁移/Worker 合同和恢复验证，不能只改前端文案。
