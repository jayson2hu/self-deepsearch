# 开发任务与执行顺序

版本 RD v1 / 2026-09-16。此文是待开发工作分解；实际状态只在[进度台账](./PROGRESS.md)维护。旧 R 编号映射见[决策记录](./DECISIONS.md)。所有路径指已有修改入口，新增文件名仅为设计建议。

## 1. 开发约定

从 DEV-01 开始建立本轮 fixture/回归基线，不重新建设平台基础。每项开发开始前阅读[产品规格](./PRODUCT_DESIGN.md)、[技术合同](./TECHNICAL_DESIGN.md)和对应 [AC 用例](./ACCEPTANCE_PLAN.md)。S/M/L 仅为相对范围，无日历工期承诺；执行人和计划日期在认领时填写。

每次交付包含：对应决策与 DEV、代码/合同/必要迁移、测试、证据、文档与状态更新。不以“组件已写”“接口可返回”单独标记完成。明确的代码任务由开发者按本文实施，本次文档工作没有替你开始开发。

## 4. 每项开发说明

### DEV-01｜样本与合同基线

输入：源码 d79b304 所代表的原评审范围与当前工作树，原验收只作历史参考。交付约 30–50 条合成/授权代表资料与 20–30 条有标准答案的查询；样本数不是线上内容数量承诺。包括长标题、同名、别名、同番号多版本、无图、日期未知、三类实体以及发布/草稿/下架状态。

单独生成 101+ 人物关联作品、201+ 厂牌关联作品及地图容量边界样本，避免普通小样本掩盖截断。测试前记录代码 SHA、配置种类、空库/升级库、是否真实 API，禁止使用真实账号历史。核对字段/游标合同和 AC 映射；与本版不一致的旧广告/偏好/来源展示断言先说明规则变更再调整，不能只删失败测试。

入口：`tests/e2e`、`scripts/release_a_preview.mjs` 及其既有夹具、Go HTTP/仓储测试、OpenAPI。回退：只移除本任务创建的隔离夹具，不碰用户数据。

### DEV-02｜查询优先布局

入口：`apps/display-web/components/site-header.tsx`、`main-nav.tsx`、`discovery-grid.tsx`、`app/page.tsx` 和既有样式。交付手机直接搜索、首页主搜索与一组目录、内容不足时收敛、简洁站点边界。后台录入/审核信息不进入用户首页。

记录空/少量/丰富目录和四种宽度截图；可选推荐不挡住搜索。回退前端布局，不改 slug/数据库；已确认的查询优先不能被旧测试中的栏目数量要求覆盖。

### DEV-03｜时间与详情合同

顺序：OpenAPI 增量定义→Go catalog/store/handler→生成类型→三类详情与 fixture→真实发布/草稿/回滚测试。仅追加 `public_updated_at` 和作品 studio 对象，不新增公开证据 DTO。详情含义及媒体独立变更边界见技术设计第 3 节。

关键证据：首次发布日期、草稿编辑不变、重新发布与回滚更新、隐藏后不外露、旧 API 缺字段仍可渲染。来源审核面板不作为待补缺陷。回退时保留后端附加字段，先回前端；不回滚公开记录。

### DEV-04｜认证续接

入口：`lib/auth-client.ts`、登录/注册/重置页面及表单、`favorite-button.tsx`、`follow-button.tsx`。交付受限 returnTo、短期标签页动作意图、回到目标后的确认、取消和目标下架处理。普通登录仍有合理默认去向。

先写 returnTo 负例和幂等关系用例，再接 UI；测试伪造链接不能静默写关系。回退可关闭续接提示但保留安全返回，不能绕开同域和会话检查。

### DEV-05｜广告按实际可用性显示

入口：AdSlot 与首页/详情/页脚调用处、预览 fixture、既有广告 E2E。交付 empty/ready/error/preview 四态与真实素材接入点；没有真实素材时生产默认 empty。普通访客和登录用户均可见 ready，使用同一内容政策。

测试占位必须受保护；无素材全页面无空白广告壳，不仅首页隐藏。真实广告未确认不接供应商、不改 CSP 放行第三方脚本。回退统一关闭素材输出，正文继续工作。

### DEV-06｜推荐偏好

入口：`personalized-work-grid.tsx`、`discovery-grid.tsx`、`hidden-work-button.tsx`、各列表调用及账号仓储。逐行执行产品矩阵，包含服务端关注作品查询，确保不是只改前端搜索。改用户文案，保留旧 API/表名。

验收搜索可找回、目录完整、推荐过滤、撤销、匿名降级和账号隔离；管理员下架仍所有入口不可见。回退不可破坏已确认语义，必要时关闭个性化推荐而不是全站过滤。

### DEV-07｜真实说明

新增匿名可读说明页，连接注册、历史、设置与页脚。逐条列出现行数据行为与内部证据来源供开发核对，面向用户不泄露内部字段/个人信息。当前只软清除就明确说明，不写“已永久删除”。

这项不包含历史数据库迁移或删除任务；Q-01 未决应在开发文档保持待确认，用户端只发布真实可兑现说明。正式发布前联系地址和政策内容由产品负责人核实，不放示例邮箱上线。

### DEV-08｜作品搜索阶段 A

入口：`app/search/page.tsx`、`lib/api.ts`、现有 Go 搜索入口和结果卡。保留原作品 API，只改准确范围说明、可读结果、条件恢复、新查询清游标、网络失败与零结果分离。偏好不再过滤明确查询。

使用 DEV-01 标注集验证番号变体、人物/厂牌名查关联作品、多版本及误匹配。回退保持 q/cursor 与 API 兼容，不依赖尚未存在的多实体端点。

### DEV-09｜多实体搜索阶段 B

先新增两个搜索端点/仓储/合约，再开放 type 标签；没有服务端端点不先上线“人物/厂牌”空壳。规范名称/别名匹配、稳定排序、查询绑定游标、公开状态过滤需真实 SQL 用例。

若加索引，交付迁移、旧数据升级、查询计划与回退说明。旧作品端点不强制迁移调用者。前端可回退到作品类型，但需准确告知能力范围。

### DEV-10｜关联作品真正分页

增加人物/厂牌关联作品端点，详情只按页请求；保留旧内嵌 works 合同过渡。时间未知排序、同日期并列、末项删除、非法游标、父实体下架都要测；下一页可直接访问且保持面包屑/主体身份。

厂牌链接使用真实 studio 对象，不从名称拼 slug。回退时可保留旧摘要预览并注明范围，不能把截断的列表声称为全量。

### DEV-11｜个人入口与现有反馈状态

复用收藏/关注/关注作品/我的反馈接口，补空状态、操作后去向和中文状态映射。原有反馈能力没有公开回复字段时只展示可证明状态，内部审核备注不下发。登录续接仍只覆盖收藏和关注，不自动提交反馈文本。

本项不包含新增三实体反馈服务模型、未读计数、多设备通知或邮件推送；确需扩展另立任务。回退不修改既有关系数据。

### DEV-12｜历史生命周期（未解锁）

在 Q-01 记录默认值、期限、老账号迁移和恢复规则后，补接口/迁移/Worker 的具体合同再开发。服务端开关、竞争写入、归档到期与恢复不可复活要同批验收；只有 UI 开关不算完成。

到期物理删除需独立执行范围、备份与不可逆说明，不能在本次文档阶段运行。旧二进制可能忽略开关，不作为直接回退方案。

### DEV-13｜SEO 技术基础

拆成 13a origin/HTTP/robots 诊断、13b 分页/canonical、13c sitemap 完整性与结构化数据。可先做 13a，13b 依赖 DEV-10 合同；13c 的资格规则按已定 D-09，与 DEV-14 共用策略合同。没有数据规模问题也要写边界用例，不为等待正式账号暂停本地开发。

入口：`lib/site.ts`、根布局及三类 metadata、`robots.ts`、`sitemap.xml/route.ts`、`sitemaps/[entity]/route.ts`、Go sitemap 查询及缓存测试。只在受保护环境验证。错误 500 必须先复现并确认根因，再实施最小修复。

回退方案覆盖旧 URL、真实状态码、地图与缓存；不得拿开放预览站作为收录测试。

### DEV-14｜SEO 正式策略（已解除产品决策阻塞）

按[正式 SEO 方案](../PRODUCT_SEO_PLAN.md)实施：中文产品与 Google 官方技术基准，统一页型资格/成人分类/图片和 OG 允许清单，unknown 安全默认，受保护测试与正式入口分离。不新增国家跳转、机翻分站、视频结构化数据或独立图片 sitemap。

拆成 14a 分类/资格与预览合同、14b 生产配置和最终入口验证、14c 站点负责人验证工具并提交。14a 可与 DEV-13 策略接口共同开发；14b/14c 必须具备真实域名和账号权限，不能拿测试站代替。若需要新增内部分类/预览许可字段，交付最小迁移、权限和旧数据抽样回填；不自动把存量素材全部标为可预览，也不无预检地使原合格页面全量 noindex。

第一份报告记录“未采集/数据不足/观测值”，无流量时不造 CTR/排名结果。正式配置与外部提交需发布记录；不能宣称代码回退即可撤销已被搜索引擎取得的内容。

### DEV-15｜集成、验收与交接

冻结本次实际交付的 DEV/AC 范围；执行前端、Go、真实 PG、账号/发布/缓存、图片保护与目标环境适用检查。普通 `go test` 跳过数据库不等于真实仓储通过，合成浏览器不等于真实部署通过。

交付证据索引、已知问题、制品 SHA、配置变更、回退步骤、未完成项与接手指南。在进度台账中逐项关闭，而不是把整个计划一次改为“完成”。
