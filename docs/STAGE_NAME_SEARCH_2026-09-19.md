# 人物艺名搜索开发与验收

日期：2026-09-19；状态：开发、部署与本次范围内验收完成。

## 需求与边界

支持通过人物公开艺名、已收录别名/曾用名查找人物，完整或部分名称均可。人物可以有多个名字，同名或相同别名不能自动合并不同人物。公开站只搜索已发布人物；内部采集预览不自动发布资料，不计正式浏览次数。

现有公开搜索已经支持艺名、原文名、罗马字及别名；作品索引包含关联人物名称/别名。本次补齐直接从人物别名表进行子串匹配（不依赖旧搜索索引的别名文本），并将内部预览由仅姓名/来源 ID 扩展到原文名、罗马字和 `aliases` 字符串数组。输入按字面匹配，`%`、`_` 不当通配符，忽略字母大小写。

当前 4196 条真实采集记录主要只有公开名称，没有独立曾用名数组。查询已有艺名可命中；新增代码支持已提供的别名，但不编造未知别名、不自动翻译姓名，不改变归档或数据库源数据。简繁异体/中文译名归一不在本次实现范围。

## 验收清单

- 公开艺名、曾用名、部分别名、大小写、原文名都能找回同一人物；同别名的两人保留两个结果，分页不重不漏。
- 隐藏/下架人物不因艺名匹配泄露；不绕过公开实体和公开搜索文档边界。
- 内部预览兼容缺失/null/非数组别名，忽略数组内非字符串；字面特殊字符和 SQL 注入样式输入安全。
- 艺名实测 `三上悠亜`、`三上`、`AIKA`；4196 条真实记录和 130 张头像数量不变。
- 所有需要模拟实体的测试仅在精确命名的隔离数据库执行，结束删除；主联调库不新增样本。
